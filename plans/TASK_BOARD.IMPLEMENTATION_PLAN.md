# Task board implementation plan

1. Replace the checklist presentation with a three-column task board: To do, In progress, and Done.
2. Keep task priority as Required or Recommended and allow mentors and managers to add tasks to the current stage.
3. Persist task status and custom tasks in the stage-progress document while remaining compatible with existing completed checklist data.
4. Allow the intern and mentor to work with task statuses; allow only mentors and managers to approve a stage transition after all required tasks are done.
5. Update lifecycle names and test the task mutation and stage-approval rules.
